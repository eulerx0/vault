Disaster Recovery & Quick Setup

            
Run this single command on any fresh Ubuntu VPS to restore all bot files and credentials instantly

          

          
        


        

          
# Run on fresh Ubuntu 22.04 / 24.04 VPS:
curl -fsSL https://raw.githubusercontent.com/eulerx0/vault/main/secrets_vault.enc -o /tmp/secrets_vault.enc && \
mkdir -p /opt/telegram-bot && cd /opt/telegram-bot && \
openssl enc -d -aes-256-cbc -pbkdf2 -iter 10000 -in /tmp/secrets_vault.enc | tar -xzf - && \
echo '✅ TeleVault Credentials and Database Restored Successfully!'
